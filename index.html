Agreement

Voxels without data on either side stay out. R = Σ|y − m| / Σ|y|, wR = √(Σw(y − m)² / Σwy²) with w = 1/σ² when σ is known, χ²/N uses σ, and Σ(y − m)²/Σy² is the figure RMCProfile logs. Pick the comparison views in Show above the map; C flips between the data and the comparison.

Symmetry

Load data to symmetrize it.

Each voxel is averaged with its symmetry equivalents that hold data; empty voxels stay out of the average. Fill empty voxels only keeps the measured values and fills the gaps; with −1 it completes Friedel pairs. Then pick Data − symmetrized above the map to see where the data break the symmetry, or Equivalents found for the coverage. Exports save the values on show.
